# piscine

> My work from the **42 Piscine**: the intense four-week C and shell bootcamp that serves as the entrance exam to the 42 network.

## About

The Piscine ("swimming pool") is where you learn to swim by jumping in: no teachers, daily projects,
weekly exams, peer evaluations and team "rushes" with people you have just met. All C code follows the
strict 42 **Norm** coding style, and only `write` is allowed for output.

Each folder contains the subject (PDF) and my solutions, one `exNN` folder per exercise.

## Modules

| Module | Topics |
|---|---|
| [`shell00`](shell00) | files, permissions, links, `ls`, `git` basics |
| [`c00`](c00) | first C programs: `write`, loops, printing characters and numbers |
| [`c01`](c01) | pointers, swapping values, arrays, `ft_strlen` |
| [`c02`](c02) | string copying and character checks (`strcpy`, `isalpha`, ...) |
| [`c03`](c03) | string compare, concatenate and search (`strcmp`, `strcat`, `strstr`) |
| [`c04`](c04) | number parsing and printing (`atoi`, `putnbr`, any base) |
| [`c05`](c05) | recursion and maths: factorial, power, Fibonacci, square root, primes |
| [`c06`](c06) | command line arguments (`argc` / `argv`): program name, parameters, reverse order |
| [`c07`](c07) | dynamic memory with `malloc` (`ft_strdup`) |

## Rushes (team projects)

| Rush | Task |
|---|---|
| [`rush00`](rush00) | draw a rectangle of given size with ASCII characters |
| [`rush01`](rush01) | solve a 4×4 "skyscraper" logic puzzle from its edge clues |
| [`rush02`](rush02) | convert a number to English words using a dictionary file |

Rushes were done in teams of two or three students.
